## Работа с таблицами
В базе данных реализованы команды для создания и удаления таблиц.
Доступные команды:
- "create_table <имя> <столбец:тип> ..." — создает новую таблицу. Поддерживаются типы "int", "str" и "bool". Столбец "ID" типа "int" добавляется автоматически в начало.
- "list_tables" — выводит имена всех созданных таблиц.
- "drop_table <имя>" — удаляет таблицу по её названию.
- "help" — показывает справку по командам.
- "exit" — выход из программы.

Пример работы:
```text
>>>Введите команду: create_table users name:str age:int
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int
>>>Введите команду: list_tables
- users
>>>Введите команду: drop_table users
Таблица "users" успешно удалена.
