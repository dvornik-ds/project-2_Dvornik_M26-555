# Примитивная база данных
Консольное приложение, имитирующее работу с базой данных. Поддерживает создание таблиц, CRUD-операции, валидацию типов данных, а также декораторы и замыкания.

## Установка и запуск

Для работы требуется менеджер пакетов `uv`.

1. Установите зависимости и соберите проект:
   uv sync
   uv build

## Управление таблицами
* `create_table <имя> <столбец:тип> ...` — создать таблицу (типы: `int`, `str`, `bool`, `ID:int` создается автоматически).
* `list_tables` — показать список всех таблиц.
* `drop_table <имя>` — удалить таблицу (требует подтверждения).
* `help` — показать справку по командам.
* `exit` — выход из программы.

Пример работы:
```text
>>>Введите команду: create_table users name:str age:int
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int
>>>Введите команду: list_tables
- users
>>>Введите команду: drop_table users
Таблица "users" успешно удалена.
